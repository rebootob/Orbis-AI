# n8n Integration

n8n is a future automation engine for deterministic workflows and integrations. It is not the system's primary AI orchestrator.

## Initial MCP posture

When Phase 8 begins, grant read-only access where practical and validate these capabilities first:

- list workflows and retrieve a workflow;
- list executions and retrieve an execution;
- identify recent failures; and
- read health status.

Write or modification capabilities remain disabled until read-only testing passes, review has succeeded, and the appropriate approval level is satisfied. Workflow modifications are Level 2; production-impacting changes may require Level 3 approval.
